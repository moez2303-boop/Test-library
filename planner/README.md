# Calm Planner: a digital product you sell once and deliver forever

A hyperlinked 2027 digital planner (and printable editions) that you sell as
an instant download on Etsy and/or Gumroad. The marketplace delivers the file
on every sale, so once it's listed there's no stock, shipping or customer
fulfilment.

Everything here is generated by code, so next year's product is one command:
`python3 generate.py --year 2028`.

## What's in the box

| File | What it is |
| --- | --- |
| `generate.py` | Builds 10 planner PDFs + 2 upload-ready zips into `dist/` |
| `verify.py` | Checks every hyperlink resolves and all 365 days exist |
| `mockups.py` | Renders 6 listing images (2700×2025) into `dist/listing/` |
| `LISTING.md` | Title, 13 tags, description, pricing, FAQ replies, ready to paste |

Product per year: 6 digital editions (Sage / Blush / Slate × Monday / Sunday
start, 466 pages, ~22,700 links each) + 4 printable editions (Letter / A4 ×
Monday / Sunday start).

## Build it

```bash
pip install reportlab pypdf pypdfium2 pillow
python3 generate.py      # ~1 min; writes dist/*.pdf and dist/*-Bundle.zip
python3 verify.py dist/*.pdf
python3 mockups.py
```

Fonts: Caladea + Carlito (SIL Open Font License, so commercial use and
embedding are fine). On Debian/Ubuntu: `apt install fonts-crosextra-caladea
fonts-crosextra-carlito`.

You don't need to run anything locally: the **Build planner** GitHub Action
builds, verifies and uploads everything as a downloadable artifact on every
push (Actions tab → latest *Build planner* run → *Artifacts*).

## Launch checklist (≈1 hour, only you can do these)

1. **Download** the `calm-planner` artifact from GitHub Actions (or use the
   files sent in chat).
2. **Etsy** (largest audience for planners): open a shop at etsy.com/sell.
   There's a $0.20 listing fee, then 6.5% transaction fee plus payment
   processing (~3% + $0.25).
   - New listing → *Digital files* → upload `CalmPlanner-2027-Digital-Bundle.zip`
     and `CalmPlanner-2027-Printable-Bundle.zip` (Etsy limit: 5 files, 20 MB each).
   - Photos: `dist/listing/01-hero.png` … `06-how-it-works.png` in order.
   - Copy title, tags and description from `LISTING.md`.
   - Category: *Paper & Party Supplies → Paper → Calendars & Planners*.
     Set "Who made it": *I did*, "What is it": *A finished product*.
   - Turn on auto-renew so the listing stays live.
3. **Gumroad** (optional second channel, no listing fees): create a product,
   upload both zips, use the same images and description. Share the link
   anywhere (Pinterest, Reddit r/digitalplanner, TikTok).
4. **Pinterest** is the best free traffic source for planners: make 5–10 pins
   from the listing images linking to your Etsy listing.

## Keeping it passive

- **Every September:** run `generate.py --year <next year>` (or push a
  one-line change to the workflow), upload the new zips to the same listing,
  and update the year in the title. Reviews stay on the listing.
- **Variations that cost nothing to add:** new colour themes (add one line
  to `THEMES`), an undated edition, or different page sizes. Each can be its
  own listing, which means more search surface.
- Buyer messages are mostly "how do I import?". The answers are pre-written
  in `LISTING.md`.

## Honest expectations

Digital planners are a proven but **crowded** Etsy category. A new shop with
no reviews typically sells little at first; income depends on search ranking,
reviews and outside traffic (Pinterest), not on the file alone. Timing is on
your side: planner demand peaks October to January, so listing now (late
October) catches the whole season. Treat the first season as the test. If
it sells, the yearly re-run is a few minutes of work.
